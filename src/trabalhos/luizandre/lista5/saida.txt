Um Large Language Model (Modelo de Linguagem em Grande Escala, ou LLM) é um tipo avançado de inteligência artificial treinado para entender, resumir, traduzir e gerar textos de forma semelhante a um ser humano.
Eles são a tecnologia por trás de assistentes virtuais e chatbots modernos, como o ChatGPT ou o Gemini.

def substituir_palavra(texto, palavra, substituicao):
    nova_linha = ''
    for elemento in texto.split():
        if elemento == palavra:
            nova_linha += substituicao + ' '
        else:
            nova_linha += elemento + ' '
    return nova_linha.strip()

from pathlib import Path

    for item in diretorio.iterdir():
        if item.is_file():
            if (item.name != 'saida.txt'):
